Getting Started
Prerequisites

    Python 3.x
    pip (Python package manager)
    A web browser supported by Selenium (e.g., Chrome, Firefox)

Setting Up Your Environment
1. Clone the Repository

First, clone the repository to your local machine using Git:

bash

git clone [git@github.com:TWadi/TerminGenie.git](https://github.com/TWadi/TerminGenie.git)
cd AppointmentScheduler

2. Create a Virtual Environment

It's recommended to create a virtual environment to keep dependencies required by the project separate from your global Python environment:

For Windows:

python -m venv venv
venv\Scripts\activate

For macOS and Linux:

bash

python3 -m venv venv
source venv/bin/activate

3. Install Dependencies

Install all the necessary dependencies using pip:

pip install -r requirements.txt

Running the Application

After setting up the environment and installing all dependencies, you can run the application using:


python main.py
